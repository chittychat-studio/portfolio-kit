# LinkedIn Portfolio Kit

A free kit from **Corporate AI Workaround** for turning your LinkedIn profile into a one-page portfolio website with Claude. No coding.

- **Kit page:** https://chittychat-studio.github.io/portfolio-kit/
- `portfolio-template.html`: the starter template. Open it in a browser to see the empty layout.
- `example.html`: a finished example, built from the template for Corporate AI Workaround.

## How it works

1. Gather your LinkedIn PDF, CV, photo, Credly links and 3 or 4 projects.
2. Attach `portfolio-template.html` and your files to a new Claude chat.
3. Send the prompt from the kit page, with your details filled in.
4. Review the page on phone and laptop, then host it free (Netlify Drop, Cloudflare Pages or GitHub Pages).

The prompt tells Claude to use only facts from your own files and never invent numbers or results.

Follow [Corporate AI Workaround on LinkedIn](https://www.linkedin.com/company/corporate-ai-workaround/) for more.
